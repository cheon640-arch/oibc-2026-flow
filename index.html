준비 채점기 예측 최적화 제출 채점기로 점수 확인

Steps

해야 할 일 9단계 · 색이 같으면 같은 묶음
준비데이터를 보고, 정리하고, 힌트를 만들어요
01준비

EDA

데이터 생김새 훑어보기

  • 파일마다 기간과 빈칸 확인
  • 발전소마다 크기와 평소 발전량
  • 예보 A·B 중 실제 날씨와 더 잘 맞는 쪽
  • 전기값(SMP)이 비싼 시간대
결과물eda.ipynb · 데이터 요약표
02준비

전처리

빈칸 채우고 이상한 값 정리

  • 예보 빈칸 채우기 (빠진 시간도 채점하니 지우면 안 됨)
  • 발전소 크기보다 큰 값, 고장 구간 정리
  • 시간 맞추기: 01:00 값은 00~01시
  • 전날 17시 이후 정보는 쓰지 않기
결과물preprocess.py · 정리된 데이터
03준비

피처 엔지니어링

모델에 줄 힌트 만들기

  • 해가 얼마나 높이 떠 있는지 (태양 고도)
  • 맑은 날 받을 수 있는 최대 햇빛 양
  • 발전량 ÷ 발전소 크기 (이용률)
  • 예보 A·B, 10시·17시 예보 모두 활용
결과물features.py
채점기제출하지 않고도 점수를 계산하는 도구예요. 모델을 만들기 전에 먼저 만들어 두세요.
04채점기 · 핵심

검증 설계 (채점기 만들기)

우리끼리 점수 매기는 도구

  • 대회 점수식을 그대로 코드로 옮기기: 점수 S = 판매 수익 − 벌점 W
  • 지난 기간 마지막 몇 주를 떼어 두고 시험지처럼 사용
  • 처음 1~2번 제출해서 우리 점수와 리더보드가 같이 움직이는지 확인
결과물scorer.py · 입력: 묶음 배정, 예측, 실제값 → 출력: 점수 S
예측날씨 예보로 내일 발전량을 맞혀요
05예측

모델링

발전소별 발전량 맞히기

  • 기준 모델: 발전소 크기 × 예보 햇빛 양
  • LightGBM 같은 머신러닝 모델
  • 전기값이 비싼 시간대를 더 정확히 맞히도록 학습
  • 발전소별로 더하기 vs 묶음 전체를 바로 예측하기 비교
결과물train.py · 예측 결과 (07에서 사용)
06예측

앙상블

여러 모델의 답을 섞기

  • 예보 A로 만든 모델 + 예보 B로 만든 모델
  • 종류가 다른 모델끼리 섞기
  • 섞는 비율은 채점기 점수가 제일 좋은 쪽으로
결과물ensemble.py
최적화묶음을 나누고 결과를 다듬어요
07최적화 · 핵심

조합 최적화

253곳을 A·B 두 묶음으로 나누기

  • 발전소마다 언제, 어느 방향으로 틀리는지 확인
  • 같이 틀리는 발전소는 서로 다른 묶음에 나눠 담기
  • 조금씩 바꿔 보며 점수가 오르는 쪽 찾기
  • 다른 기간으로도 점수가 좋은지 다시 확인
결과물partition.py · composition.csv
08최적화

후처리

말 안 되는 값 바로잡기

  • 밤에는 발전량 0
  • 발전소 크기보다 큰 값은 최대치로 자르기
  • 묶음 전체가 계속 많게(적게) 나오면 보정
결과물postprocess.py
제출점수가 오른 버전만 골라서 내요
09제출

제출

파일 내고 리더보드 확인

  • composition.csv와 묶음별 예측 CSV 제출
  • 하루 3번, 대회 기간 전체 20번까지
  • 무엇을 낼지는 리더보드보다 우리 채점기 점수로 결정
결과물제출 파일 · 제출 기록표 (언제, 무엇을, 몇 점)
